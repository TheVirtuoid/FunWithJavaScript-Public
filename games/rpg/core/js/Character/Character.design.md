# Character

A player and non-player character in the game. 

## constructor
- ` new Character(args)` - creates a new character.
    - `args` - an object containing the following properties:
        - id(uuid): The unique identifier of the character. Auto-generated by the system upon creation of the character. Required.
        - name(string): The name of the character. Required.
        - race(raceType): The race of the character. Required.
        - characterClass(characterClassType): The class of the character. Required.

## Properties
All properties are read-only.
- `id` (uuid)
- `name` (string)
- `abilities` (Map<Ability>): The abilities of the character.
- `attributes` (Map<Attribute>): The attributes of the character.
- `inventory` (Map<Object>): The inventory of the character.
- `race` (Object): The race of the character. Object generated by Race.GetRaceData
- `characterClass` (CharacterClass): the class of the character. Instance of CharacterClass

 ## Methods
- `setName(name)` - changes the name of the character
    - Throws if not a string or is an empty string.
- `setCharacterClass(characterClassType)` - changes the class of the character
    - Throws if invalid characterClassType.
- `addAbility(Ability)` - adds an ability to the character
    - Throws if a duplicate.
    - Throws if ability is not an instance of Ability
- `removeAbility(abilityType)` - removes an ability from the character
    - Throws if invalid abilityType.
    - Returns ability removed.
    - Returns undefined if ability was not found.
- `getAbility(abilityType)` - returns the ability of the character
    - Returns undefined if ability was not found.
- `addAttribute(Attribute)` - adds an attribute to the character
    - Throws if a duplicate.
    - Throws if attribute is not an instance of Attribute
- `removeAttribute(attributeType)` - removes an attribute from the character
    - Throws if invalid attributeType.
    - Returns the removed attribute instance.
    - Returns undefined if the attribute was not found.
- `getAttribute(attributeType)` - returns an attribute of the character
    - Returns undefined if attribute was not found.
- `addInventory({ Equipment, quantity })` - adds a quantity equipment to the character
    - Throws if Equipment is not an instance of Equipment
    - Throws if quantity is not an integer.
    - Positive and negative numbers are allowed.
- `removeInventory(equipmentType)` - completely removes inventory from the character
    - Throws if invalid equipmentType.
    - Returns the removed inventory object.
    - Returns undefined if the equipment was not found.
- `getInventory(equipmentType)` - returns the number of equipment possessed by the character
    - Returns a number. If equipmentTYpe is not found, returns 0.
