# Character

A player and non-player character in the game. 

## constructor
- ` new Character(args)` - creates a new character.
    - `args` - an object containing the following properties:
        - id(uuid): The unique identifier of the character. Auto-generated by the system upon creation of the character. Required.
        - name(string): The name of the character. Required.
        - race(symbol): The race of the character. Required.
        - characterClass(symbol): The class of the character. Required.

## Properties
All properties are read-only.
- id(uuid)
- name(string)
- abilities(Map<Ability>): The abilities of the character.
- attributes(Map<Attribute>): The attributes of the character.
- race(Race): The race of the character
- characterClass(CharacterClass): the class of the character

 ## Methods
- `setName(name)` - changes the name of the character
- `setRace(raceType)` - changes the race of the character
- `setCharacterClass(characterClassType)` - changes the class of the character
- `addAbility(Ability)` - adds an ability to the character
- `removeAbility(abilityType)` - removes an ability from the character
- `getAbility(abilityType)` - returns the ability of the character
- `addAttribute(Attribute)` - adds an attribute to the character
- `removeAttribute(attributeType)` - removes an attribute from the character
- `getAttribute(attributeType)` - returns an attribute of the character
