# PlayerCharacter

This defines the class for creating a new player character.

## rules
- must extend the `Character` class
- must add the following abilities:
    - Strength
    - Dexterity
    - Intelligence
    - Wisdom
    - Charisma
- must add the following attributes as Character attributes
    - Level
    - Experience
    - Hit Points
    - Attack Bonus
    - Money
- must add the following attributes as Saving Throw attributes
    - Death | Poison
    - Wands
    - Paralyze | Stone
    - Dragon Breath
    - Spells
- Each ability is intially loaded with a `3d6` die roll.
- Set the Level attribute to 1
- When creating a new character, the raceType, classType, and the name must be provided
